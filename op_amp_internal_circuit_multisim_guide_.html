1. Introduction and learning objectives

An operational amplifier (op-amp) is a high-gain differential amplifier. It amplifies the voltage difference between its non-inverting (+) and inverting (−) inputs. With suitable feedback components, it can perform amplification, addition, subtraction, filtering and many other analog functions.

After this lesson, you can…
  • Identify the main internal functional blocks.
  • Explain how a small differential input becomes an output signal.
  • Build a non-inverting amplifier test circuit in Multisim.
  • Calculate closed-loop gain and expected output voltage.

2. Internal circuit and functional blocks

The signal generally passes from the input differential stage through voltage-gain and level-shifting stages to the output stage. A bias network provides suitable operating currents to the internal transistors.

1. Differential input stage

Accepts the two input voltages and responds mainly to their difference. It usually provides high input resistance and helps reject signals common to both inputs.

2. Voltage-gain stage

Provides most of the op-amp's open-loop voltage gain. Internal active loads and compensation may be included.

3. Level-shifting stage

Moves the DC voltage level to a suitable value so the output can be correctly centred for positive and negative signal swings.

4. Output stage

Supplies load current with relatively low output resistance. Many op-amps use a class-AB or push-pull arrangement, subject to the IC design.

5. Bias network

Creates reference currents that set transistor operating points. A real IC may also include frequency compensation and protection circuits.

3. Multisim circuit: non-inverting amplifier

This example tests an op-amp using negative feedback. In Multisim, place an op-amp model, two resistors, an AC sine source, DC supply rails, ground and an oscilloscope. Component names and power-pin visibility depend on the selected model.

Design tip: Check the selected op-amp model's pin configuration and supply-voltage limits before running the simulation. Make sure all required power and ground connections are present.

Suggested Multisim setup

  1. Start a new design and place an op-amp model (for example, a 741 model) or a suitable ideal op-amp.
  2. Connect the non-inverting (+) input to a sine source: 1 kHz, 0.5 V peak, 0 V offset.
  3. Connect Rg = 10 kΩ from the inverting (−) input node to ground.
  4. Connect Rf = 10 kΩ from the output back to the inverting (−) input node.
  5. Connect the supply rails according to the selected op-amp's pinout and model requirements. Add ground.
  6. Attach an oscilloscope: Channel A to Vin, Channel B to Vout, and both reference grounds to circuit ground.
  7. Run transient simulation and compare input/output amplitude and phase.

5. Important equations

Differential input

Vd = V+ − V−

The op-amp's open-loop output is approximately Vout = AOL(V+ − V−), where AOL is open-loop voltage gain. The output is limited by the supply rails in a real device.

Non-inverting amplifier gain

Av = Vout / Vin = 1 + (Rf / Rg)

For Rf = 10 kΩ and Rg = 10 kΩ:

Av = 1 + (10 kΩ / 10 kΩ) = 2

Input and output amplitudes

Vout(peak) = Av × Vin(peak) = 2 × 0.5 V = 1.0 V

Ideal op-amp assumptions with negative feedback

  • Input current is approximately zero.
  • The voltage difference between the inputs is approximately zero while the amplifier operates linearly with negative feedback.
  • The output has not saturated and remains within the model's operating limits.

6. Solved numerical problems

Problem 1 — Calculate gain

Given: Rf = 20 kΩ, Rg = 10 kΩ. Find non-inverting voltage gain.

Formula: Av = 1 + Rf/Rg

Av = 1 + 20/10 = 3

Answer: Voltage gain = 3.

Problem 2 — Find output voltage

Given: Av = 4 and Vin = 0.2 V peak. Find output peak voltage.

Vout = Av × Vin = 4 × 0.2 = 0.8 V peak

Answer: 0.8 V peak, assuming no saturation.

Problem 3 — Find feedback resistor

Given: Non-inverting gain Av = 6 and Rg = 2 kΩ. Find Rf.

Av = 1 + Rf/Rg, so Rf = (Av − 1)Rg.

Rf = (6 − 1) × 2 kΩ = 10 kΩ

Answer: Rf = 10 kΩ.

7. Advantages, limitations and common mistakes

Advantages

  • High voltage gain.
  • High input resistance in many designs.
  • Useful for amplification and signal conditioning.
  • Feedback allows predictable closed-loop gain.

Limitations

  • Finite bandwidth and slew rate.
  • Output swing and input range are limited.
  • Offset voltage and input bias currents are non-zero.
  • Load current and stability limits must be respected.

Common mistakes

  • Forgetting circuit ground or supply connections.
  • Connecting feedback to the wrong input.
  • Confusing peak voltage with peak-to-peak voltage.
  • Expecting an output beyond the supply range.
  • Assuming every op-amp has the same pinout.
